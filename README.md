# Customer Churn Prediction

## Project Overview
This project uses machine learning to predict whether a customer is likely to churn based on customer behavior and account-related features.

## Tools Used
- Python
- Pandas
- Scikit-learn
- Machine Learning
- GitHub

## Model Used
Random Forest Classifier

## Dataset
A synthetic customer churn dataset was created using Scikit-learn.

## Features Used
- Monthly Charges
- Tenure
- Support Calls
- Contract Length
- Usage Score

## Target Variable
- Churn

## Result
The model achieved an accuracy of 93.0%.

## Skills Demonstrated
- Data preparation
- Train-test split
- Machine learning model training
- Model evaluation
- Classification
